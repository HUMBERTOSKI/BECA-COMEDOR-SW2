# Sistema de Control de Comensales UABJB

Proyecto de Software 2 desarrollado mediante Scrum.

Tecnologías: PHP, MySQL, HTML, CSS y JavaScript.

El sistema permitirá registrar estudiantes becarios, generar credenciales QR y controlar la autorización y entrega de alimentos en el comedor universitario.

El desarrollo estará organizado mediante historias de usuario y Sprints en Jira.
